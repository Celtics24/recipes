# המתכונים שלי

אתר אישי לשמירת מתכונים - קישורים, מתכונים כתובים והערות, מחולקים לקטגוריות.

- **אתר סטטי** (index.html / app.js / style.css) מתפרסם דרך GitHub Pages.
- **Backend:** Cloudflare Worker נפרד (`worker.js`) עם KV namespace משלו - משתמשים (מייל + סיסמה), סשנים ומתכונים פרטיים לכל משתמש.
- כל אחד עם הקישור יכול להירשם ולנהל את המתכונים שלו. כל משתמש רואה רק את המתכונים שלו.
- המייל הוא מזהה בלבד (ללא אימות מייל); איפוס סיסמה דרך קוד שחזור שמוצג פעם אחת בהרשמה.
